02 · Wellbeing

A gentle nudge to look up from your phone.

Screen Time Reminder counts how long you have been using your phone in one stretch, and sends a single calm reminder when a session runs long. There are no streaks, no scores and no guilt — just one honest number and a reason to put the phone down for a minute.

In one line: Screen Time Reminder is a free Android app that tracks continuous phone use and sends one gentle break reminder when a session runs long, keeping a seven-day history and asking for no account, no ads and no internet access.

Download the APK Source on GitHub

Free. Android 8.0 and later. Distributed as a signed APK from the project’s GitHub releases.

What it does

  • One live number — how long the current stretch of phone use has lasted.
  • One calm reminder when a session runs long, instead of a stream of notifications.
  • A seven-day history, so a bad afternoon is visible as a pattern rather than a verdict.
  • Nothing to keep up. No streaks, no scores, no daily target to miss.

How it works

Android exposes app-usage information to apps that are granted usage access. Screen Time Reminder reads which app was in the foreground and when it was left, and turns that into a single continuous-use timer. When the timer passes the threshold, it posts one notification and resets. Locking the phone or switching to a different session ends the count.

It is deliberately a reminder, not a manager: it cannot block apps, close them or shame you into closing them. The only action it takes is one notification you can dismiss.

What it does not do

The app does not request the internet permission at all. That is not a promise in a policy document — it is a permission that is absent from the manifest, so the app has no technical way to send anything anywhere. Every number it records stays in its own private storage on the phone, is removed when you uninstall, and is never uploaded, sold or shared.

There are no accounts, no advertising SDK, no analytics SDK and no crash reporter. The project’s source is public, so the claim can be checked rather than trusted.

Common questions

Does Screen Time Reminder block apps?

No. It is a reminder, not a blocker or a parental control. It counts continuous use and sends one notification when a session runs long; it cannot close or restrict anything.

Does it need an internet connection?

No — and it could not use one. The app does not request the internet permission, so it has no technical way to send or receive data.

What permission does it need?

Usage access, which is Android’s name for permission to see which app is in the foreground and for how long. Without it the app has nothing to measure.

Does it keep a streak or score?

No. There are no streaks, scores, badges or daily targets. You get a running count and a seven-day history, and that is all.

Is it really free?

Yes. It is free to download and use, with no ads, no subscription and no in-app purchases.
